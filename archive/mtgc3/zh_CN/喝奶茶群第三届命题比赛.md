### 三、报名与提交方式

**喝奶茶 2 群成员和 Discord 上 MTG Contest Server 内的成员**可以报名本比赛，此处专注于喝奶茶 2 群的提交规则。

**只允许提交回放文件或者回放字符串文本，不支持视频或截图提交。**回放文件是一种存储你游戏过程的文件，用于快速且完备的回放验证；回放字符串文本则是一种文本化的回放文件格式，可以在游戏内通过指令或模组获得。

可以选择直接在群内公开提交，也可以选择私聊晨曦（@1549225958）提交。公开提交时，请同时进行合适的@提醒。

在提交后一段时间内，你会收到明确的验证截图回执，并得知你的分数和分数是否有效，若无效会告知无效原因。对于回放无法解析的提交，回放不会归档，对于回放可以解析但不符合规则的提交，回放归档但分数不计入排行榜。

#### 回放提交流程和要求

若你使用 Steam 版：

- 记录你的回放的 replayid
- 进入你的游戏目录，打开 `./saves/replays/`，找到与你 replayid 同名的文件
- 提交此文件

若你使用移动端 Modifitode 版 ：

- 确保你的 Modifitode 版本为最新版本
- 记录你的回放的 replayid
- 进入主菜单，点击 MOD 设置，再点击导出，输入你的 replayid 并确认
- 此时你的回放数据已经被复制到剪切板，请复制到一个文件或者在线文档链接
- 提交此文件或在线文档链接

若你在不支持回放导出的版本上联网游玩，你可以访问群文件或 GitHub(mtgpublic/mtgcontest) 获取如下类型的回放下载脚本：

- PowerShell 单行脚本，适用于 Windows
- Python 脚本
- Bash 脚本，适用于 Linux

若你使用脚本下载：

- 输入用户名和密码
- 若登录成功，输入你要下载的 replayid
- 下载成功后，你会在执行脚本的目录获得回放字符串文本文件，同时剪切板内会有回放字符串文本
- 提交此文本

你可以通过其他方式获得回放文件或者回放字符串文本并提交。

#### 回放自主验证

本次比赛提供验证脚本和单行验证脚本指令，你可以访问群文件或 GitHub(mtgpublic/mtgcontest) 获取验证脚本，以方便自主验证，避免提交不符合规则。
