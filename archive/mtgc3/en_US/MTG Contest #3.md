### **III. Registration & Submission Procedures**
Members of **MTG Group 2** and the **MTG Contest Server on Discord** are eligible to register for the contest. The submission rules outlined here focus exclusively on **MTG Contest Server**.

**Only replay files or replay string texts are accepted as submissions. Videos or screenshots are not supported. ** A replay file stores your gameplay data for quick and complete replay verification. A replay string is a text-formatted version of a replay file, which can be obtained in-game through commands or mods.

Simply direct message any Moderator in the MTG Contest Server and submit your replay file or replay string.

After submission, participants will receive a definite acknowledgment of Verification Receipt, along with their score and whether or not the score is valid. If the score is deemed invalid, the specific reasons will be communicated.

#### **Replay Submission Procedure and Requirements**

If you are using the Steam version:
1. Record your replay ID.
2. Navigate to your game directory and locate `./saves/replays/`.
3. Find the file with the same name as your replay ID.
4. Submit this file.

If you are using the mobile replay manager version:
1. Confirm that your replay manager version is the latest version.
2. Record your replay ID.
3. Go to the main menu, click MOD Settings, then click Export, enter your replay ID, and confirm.
4. Your replay data will now be copied to your clipboard. Save the data to a file or an online document link.
5. Submit the file or the link.

If you play online on a version that does not support replay export, you can get replay download scripts of the following types from the GitHub (`mtgpublic/mtgcontest`):

- PowerShell one-liner (For Windows)
- Python script
- Bash script (for Linux)

If you use a script to download:

1. Enter your username and password

2. If sign-in succeeds, enter the replay ID you want to download

3. After a successful download, you will get a text file containing the replay string in the directory where you ran the script, and the replay string will also be copied to your clipboard

4. Submit this file or text

Alternative methods to acquire and submit replay files or replay string texts are also acceptable.

#### Replay Self-Verification

This competition provides verification scripts as well as single-line verification commands. You can obtain these scripts from the group files or from GitHub (mtgpublic/mtgcontest) to perform self-verification, helping to avoid submissions that do not comply with the rules.
